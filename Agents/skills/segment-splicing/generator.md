# 分镜衔接 · 生成

对象是**已经封装好的投喂单元**，不是分镜镜头。一条封装单元恰好一条账。`entries` 的条数必须等于封装单元数。`shot_id` 必须原样照抄该单元的 id，形式是 `封装单元 N/M`（例如 `封装单元 1/3`；旧稿标题若是投喂单元，则是 `投喂单元 N/M`）。不要把多个单元收成更少的段，不要写成 `封装单元 1`，不要改成 `1`、`2`、`3`，也不要写成 `S01`。

只判**单元与单元之间**的缝。段内五维（轴线、视线、动作匹配、道具、段内景别节奏）不进主结果。

权威口径来自段缝规程，这里只留执行时要用的判断。拿不准时跟分流表，不要把 ① 当成唯一默认。剧情段默认 ②。

## D 锁（每条相邻缝恰好一个）

| 锁 | 名字 | 什么时候用 |
|---|---|---|
| ① | 末帧定格承接 | 动作、对白或一镜到底真的跨过这一刀还在继续 |
| ② | 换机位硬切 | 剧情段、组内已经在换机位，或时间/地点断开。观众读到的是剪辑 |
| ③ | 空镜过渡 | 情绪落地、声先入、时空跳。不拿来躲冲突 |
| ④ | 技巧型转场 | 有名字的转场手法。不替代 ①②③。一集最多 3 处 |

第一个封装单元没有入缝，`d_lock` 写 `none`。

### ① / ② 分流

- 跨组的连贯动作、一句话被拆开、单镜跟拍被切开 → ①
- 剧情段划分、组内本来就多机位、换场换时间 → ②。不要为了保险改成 ①
- 组间时间或空间跳 → ② 或 ③
- 情绪段落收尾 → ③
- 无论 ① 还 ②，缝的两侧都要换机位或换视角。禁止同机位又同景别硬接

### 景别

① 的末镜终点景别和下一镜起点景别必须同档（大远景、远景、全景、中全景、中景、中近景、近景、特写、大特写）。同档靠换角度，不靠换景别。

### ① 的可截尾

① 必须有可截计划，四件事都要在计划里说清：人在场、朝向可用、背景锚点可见、无压屏。尾帧是上一段渲染完成后的真实末帧截图，不是重画。只有尾巴计划里就不可用时才重绘，或这一镜明确锁住 t=0 构图时才另出一张静帧。

### ② 的写法

② 不写定格、不写末秒冻住。末段只留接口余量。`end_image` 空。不要把上一段尾巴当首帧，也不要当参考图。

### ③ 空镜

三种用法：情绪空镜、音效桥、时空转场。一集最多 3 处，每处 1–2 秒。必须是具体画面。不得用来躲开该打的冲突。通常不接人物尾帧。

### ④

必须点名转场手法（形状匹配、前景遮挡、甩镜、闪白、画中画、声先画后等）。一集最多 3 处。

### 人物进出

后一段新出现的具名人物要有入画、声先入、空镜，或上一镜句尾一句交代。人走了要写出去向。

## 写法

普通衔接、独立批量强连续、首帧增强、调度增强、视频延长强连续是提示词封装已经用过的写法，不是第二套 D 锁。账本不要再选 `writing_mode`。

官方没有单独的视频延长接口。需要延长时，D 锁走 ①，`video_mode` 用 `first_frame` 或 `first_last_frame`。不要把末态继承、拼接节点、换机位、可变数据写进投喂正文。

## 官方提交参数（MiniMax H3）

没有单独的视频延长接口。一次调用只能是下面一种，不能混用：

| video_mode | 画面 |
|---|---|
| text | 不送图 |
| first_frame | 只送一张首帧。① 的首帧来源是 `previous_tail`（上一段真实尾帧）。重绘或锁 t=0 时来源是那张静帧的资产 id |
| first_last_frame | 首帧同上，再加这一镜自己的 `end_image` 作为尾帧 |
| reference | 只绑这一镜自己的资产图，最多 9 张。`end_image` 空。不送上一段尾巴 |

① → `first_frame`，或这一镜自己也要锚住结尾时用 `first_last_frame`。这一发不要再带人物或场景参考图。

② → 有静帧就 `reference`，没有就 `text`。

③ → 场景静帧 `reference`，否则 `text`。不接人物尾帧。

④ → 仍然选上面四种里的一种，并写上转场手法的名字。

第一个封装单元，或新场景的普通切：`reference`（没有图就 `text`），不接上一段尾巴。只有明确锁 t=0 构图时才用设计好的首帧。
