## 负向词

权威在漫剧老李资产引擎对应 md，词表按原文摘录。每个出图提示都带上本表；正向目标是一张完整板、同一张脸、头到鞋都在画内。

### 所有资产板必含

来源：delivery-pitfalls.md

`fifth panel`, `extra panel`, `different face`（或 `second face`）, `text`, `watermark`

### 角色四格板（必写）

来源：character-portrait-templates.md §7.6

```
duplicate front view panel, extra fifth panel, five-panel layout,
standalone main portrait beside the four-grid sheet, repeated view angle,
sharp facial features on body views, detailed eyes on secondary views,
a second recognizable face, mosaic censoring bar, pixelated face,
headless figure, cropped head, head out of frame,
text, letters, words, caption, label, subtitle, watermark, logo, signature, ui elements, chinese characters
```

「马赛克」要转译成「无脸（无面部细节）」，不把 `mosaic` / `pixelated` / `censored` / `马赛克` / `像素化` / `打码` 当正向词写进提示。图底声纹波形和不超过 8 个词的英文音色标签可以留在图上，其余文字不入图。

### 道具四格板

来源：prop-template.md

```
duplicate view angle panel, extra fifth panel, five-panel layout, standalone oversized prop render beside the four-panel sheet, repeated front view, human hand, person, silhouette
```

道具只展示自身，不用手持。
