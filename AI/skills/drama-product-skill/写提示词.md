# 短剧植入

问什么、镜头怎么写，以同目录的子技能为准。本文件只负责接到本机的 JSON。

子技能写出的导演段落放进 `script` 和 `shots[].prompt`。本机交稿尽可能详细。可见的和听得见的都留下。只删空泛的质量词，例如「电影感」「高级」。不另交压缩版。

`script` 按镜头拼完整导演段。每一镜写切镜、手和身体怎么动、其他人各自的小动作、环境里这一拍能看见的东西、声音，以及锁句（光、人、位置、面向、机位侧）。

`storyboard` 先写空间平面，再每镜一段：机位侧、画内的人和朝向、视线、主动作、其他人、对白、声音、落幅。按场面写全，不缩成一句。

`shots[].prompt` 与该镜在 `script` 里的那段相同，保留同样的细节。

子技能若要求「只交一条纯文本提示词」，以本文件的 JSON 为准。不要在 JSON 外面再交一段正文。

不要输出 `@Image1`，也不要输出 `@图片1`、`@Video1`、`@Audio1`。上传图 id 进资产的 `references`。镜头 `images` 只填已经生成的资产 id。一个参考只承担一件事：定妆锁人，商品图锁商品，不交叉。

时长和画幅不写进镜头正文。画幅 9:16，帧率 24，每镜 `duration` 是 4 到 15 的整数秒，都写在 JSON 字段里。镜头正文不写 `0–3秒`。

内部标签可以留在简报，不出现在 `shots[].prompt`。

只返回一个 JSON 对象。`script`、`storyboard`、`image_prompts`，以及 `assets` 和 `shots` 里的提示词全部用中文。

## 出镜时接上

本技能只属于短剧植入。写 JSON 时不要抄下面三句。参考图出镜时，出片程序会把它们接上。首尾帧模式不接这三句。

```render-video-lock
锁这一镜已经出现的脸、衣服和商品外形。不要换脸，不要换衣服，不要新造第二件商品，不要特写商标文字。全程无字幕、无对白文字叠加。
```

```render-video-next
这一镜是上一镜的下一刀。接上一镜的落幅、左右关系和光线。已经出现的人不要换脸，已经出现的商品不要换一件。不要换房间。
```

```render-video-tail
最后一张参考图是上一镜的实际尾帧，只承接上一镜已经有的人和场景，不要照抄它的景别和构图。
```
