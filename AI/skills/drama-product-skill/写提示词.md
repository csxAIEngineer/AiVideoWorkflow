# 短剧植入

同一场戏，同样的人，同一件商品。观众先懂人和卡点，再看见商品被用到。语气是一集竖屏小戏，不要写成口播、说明书或汽车广告。

## 交稿

只返回一个 JSON 对象。`script`、`storyboard`、`image_prompts`，以及 `assets` 和 `shots` 里的提示词全部用中文。不要在 JSON 外面写锚点链接、检查清单或引导语。不要向用户追问画幅、时长或语言。简报已经锁定人物、处境、商品和植入拍。

生图按 iCreat 的静帧来写。出镜按 MiniMax 的参考图视频来写运动。下面三条出镜围栏由出片程序拼接，不要写进 script，也不要写进 `shots[].prompt`。

## 规格

- 画幅 9:16。
- 帧率 24。
- 每镜 `duration` 是 4 到 15 的整数秒。对白要能在这一镜里说完。
- 一镜一个机位、一个主要运动。
- 镜头按钩子、冲突、植入、收束来写，不抄案例里的镜数。人少，竖屏里站得住，通常就是简报里的那一两个人。

## 四拍

第一拍是钩子。人物已经在处境里。一个机位看清是谁、卡在什么。不要从商品、标志或白底空镜开始。这一镜的 `images` 可以没有商品。

第二拍是冲突。关系或目标再紧一扣。商品可以出现在桌上或身侧，但还不是这一镜的动作。

第三拍是植入。只有一个机位。人物用这件商品做一件能看懂的事：拿起、递出、打开、戴上或用完。不环绕，不念参数，不切到另一间棚。

第四拍是收束。停在简报写明的那一拍：关系、动作，或商品被留下。人先被看见。没有口播。

## 轴线

写编号分镜之前，先在 `script` 里写一行轴线：人物面向哪，商品从人物的哪一侧进入，机位默认在人物的哪一侧，两个人谁在左谁在右。

下一镜的起点复述上一镜的朝向和左右关系。可以改景别，可以换到对手角度。不得换房间，不得跳轴把左右对调，不得换成另一件商品。

## 工作流

1. 读 `案例.md`。只选 D1、D2、D3、D4 里最接近这场植入的一条，在 `script` 里点名编号。不要贴链接。
2. 只借商品在哪一拍、以什么动作进入。不借人名、台词、商品、地点和镜数。不要把几条案例混成一条。
3. 先写轴线，再按下面七段写 `script`。
4. 按资产规则写 `assets`，按分镜规则写 `shots`。`shots[].prompt` 是 `script` 编号分镜里的一镜。
5. 核对负面清单，然后只交 JSON。

## 七段

1. 开场：总时长、画幅 9:16、帧率 24、镜头数，以及点名的案例编号。
2. 人物锁定：谁和谁，关系，脸、发型、衣服、体态。不写年龄数字。没有第二个人就写没有。
3. 处境：房间或地点、卡点、光线。同一场戏不换地点。
4. 商品锁定：哪一件，颜色，必须被认出来的轮廓和材质。按外形写，不靠商标文字。
5. 植入和配比：商品在哪一拍进入，人物用它做什么。一句配比写多少是人和关系，多少是商品被用到的那一下。后面的分镜照这句执行。
6. 编号分镜：一镜一个机位。每镜写机位、运镜、起点、人物怎么动、商品在不在、做什么、终点，以及 4 到 15 的整数秒。第二镜起，起点复述上一镜的朝向和左右关系。
7. 风格和负面清单：实拍小戏。排除口播、价格、成分、容量、折扣、商标文字特写、字幕、水印、乱码文字、换脸、换衣服、第二件同款、第一镜白底商品、跳轴、换房间。

## 对白

有人声时，在 `script` 里写成 `==人名：原句==`。原句不超过 40 个字，里面不要写年龄。`shots[].dialogue` 写同一句，格式是「人名：原句」，并写明谁在画内开口。

没有对白时，`dialogue` 为空字符串，并在这一镜写明本镜无对白。

不要另写广告旁白。`narration` 只放用户图上已经给出的原句旁白，没有则为空字符串。不要改字。

重点用 `==人物锁定==` 这种不带冒号的包法。带冒号的 `== ==` 只留给对白。

## 资产

每个要出镜的人一张定妆，`subject_kind` 用 `character`，`view` 为 `single`。标题里写明定妆。脸、发型、衣服在这张上锁死。定妆不拿商品，除非这件商品本来就戴在身上。

商品三张，`subject` 相同，`subject_kind` 用 `prop`，`view` 分别是 `hero`、`three_quarter`、`macro`。三张都要自己写好，不要等出片程序补。英雄图和四分之三的 `depends_on` 为空字符串。微距的 `depends_on` 填英雄图 id。英雄图是静物，用这场戏的光线，画面里没有手。

手持或使用中的样子是变体：`view` 为 `single`，`depends_on` 填英雄图 id。只加这一个动作，不换商品。没有这个动作就不要写变体。

场景一张，`subject_kind` 用 `location`，`view` 为 `single`。写从哪看、前后景，以及一到三个固定锚点。场景里不放人物，也不把商品拍成特写。

其他道具保持单张，不要写成 `hero`、`three_quarter` 或 `macro`。这样出片程序只会把广告商品认成那一件。

上传图只是参考。商品图的 id 写进商品三张的 `references`，例如都写 `["U1"]`。人物图的 id 只写进对应定妆的 `references`。不要把人物图写进商品，也不要把商品图写进定妆。不要把上传图 id 写进 `depends_on` 或镜头 `images`。

不要写 `front`、`side`、`back`。不要给角色或商品拆车辆三视图。

## 分镜引用

`images` 只列这一镜看得见、且已经写进 Image-Node 的生成资产 id。

钩子可以只有定妆和场景。植入拍放上定妆、要用的那张商品图、场景。微距只在这一拍确实要看清那个动作时加入。商品没出场的镜头不要把商品 id 写进去。

## 这些句子作废

不要执行：

- 一秒一条，或先写满固定个数的空镜。
- 第一镜就是白底旋转商品，或每一镜都让商品出镜。
- 口播价格、成分、容量、折扣或口号。
- 向用户追问画幅、时长、语言或参考图。
- 用英文写提示词，或在 JSON 外面再交一段正文。
- 把出镜围栏抄进 `script` 或 `shots[].prompt`。
- 写成行驶中的汽车广告，或要求车辆正面、侧面、背面。

## 出镜时接上

本技能只属于短剧植入。写 JSON 时不要抄下面三句。参考图出镜时，出片程序会把它们接上。首尾帧模式不接这三句。

```render-video-lock
锁这一镜已经出现的脸、衣服和商品外形。不要换脸，不要换衣服，不要新造第二件商品，不要特写商标文字。全程无字幕、无对白文字叠加。
```

```render-video-next
这一镜是上一镜的下一刀。接上一镜的落幅、左右关系和光线。已经出现的人不要换脸，已经出现的商品不要换一件。不要换房间。
```

```render-video-tail
最后一张参考图是上一镜的实际尾帧，只承接上一镜已经有的人和场景，不要照抄它的景别和构图。
```
