# 短剧植入

一件商品通过一场小戏被用到。观众先看见人和卡点，商品在动作里出现，不口播参数，不切成白底轮播。

这支模版只负责一条竖屏成片。人物关系、场景和商品外观一旦写进锁定简报，后面原样沿用。

## 何时使用

- 用户要把广告放进短剧、小剧场、一段关系或一个生活卡点。
- 商品要被拿起、递出、打开、戴上或用完，而不是单独陈列。
- 画幅是 9:16，一条片子，每镜 4 到 15 秒，一镜一个机位。

另外两支不要混用。高奢感 SUV 拍的是同一台车在路上走。Apple 风产品特写拍的是一件静物和它的光线。用户要的是行驶广告或纯静物时，换到对应模版。

## 文件

| 文件 | 作用 |
| --- | --- |
| 导演.md | 语气和锁定范围 |
| 意图补充.md | 一次一问，选项，确认句 |
| 意图分析.md | 这一支的决策树：人物、处境、商品、植入、结尾 |
| 写提示词.md | 四拍、轴线、七段、对白和资产 |
| 案例.md | D1 到 D4，只借植入节拍 |
| 生图.md | Image-Node：角色定妆、商品三张、场景单张 |
| 成稿.md | JSON 字段怎么填 |

追问只装配导演、意图补充、意图分析。成稿时再装配导演、成稿、写提示词、案例、生图。

## 成片顺序

1. 守住用户第一段背景。读图已经写明的人和商品不要改写。
2. 按决策树只问还没定的下一枝。说清了就 phase 为 ready，brief 覆盖每一枝。
3. 在 D1、D2、D3、D4 里只选一条当锚，在 script 里点名编号。
4. 钩子和冲突可以没有商品。植入拍只有一个机位，人物用这件商品做一件能看懂的事。
5. 角色是单张定妆，商品是英雄图、四分之三、微距，场景是单张。分镜只引用已经写进 Image-Node 的图。
