# 短剧植入

先走对应子技能，再由适配层交 JSON。

一件商品通过一场小戏被用到。观众先看见人和卡点，商品在动作里出现。问什么、镜头怎么写，以同目录的子技能为准。导演、意图、写提示词和成稿只负责接到本机。

## 何时使用

- 用户要把广告放进短剧、小剧场、一段关系或一个生活卡点。
- 商品要被拿起、递出、打开、戴上或用完，而不是单独陈列。
- 画幅是 9:16，一条片子，每镜 4 到 15 秒，一镜一个机位。

另外两支不要混用。高奢感 SUV 拍的是同一台车在路上走。Apple 风产品特写拍的是一件静物和它的光线。用户要的是行驶广告或纯静物时，换到对应模版。

## 文件

| 文件 | 作用 |
| --- | --- |
| 导演.md | 这是短剧植入。先按子技能分轨 |
| 意图补充.md | 回复格式。问哪一枝以访谈技能为准 |
| 意图分析.md | 访谈技能的阻塞问题，加上手怎么碰到这件商品 |
| seedance-interview.md | 访谈技能正文，和意图文件里的一份相同 |
| seedance-interview-short.md | 短访谈正文，和意图文件里的一份相同 |
| 写提示词.md | 把导演段落放进 JSON |
| 成稿.md | JSON 字段 |
| 案例.md | D1 到 D4，一个动作、一个终点、一个声音 |
| 生图.md | 定妆、商品三张、场景单张。静帧只锁身份 |
| seedance-*.md | 写法子技能，和三份生成前要读的参考 |

追问只装配导演、意图补充、意图分析。成稿时再装配导演、成稿，以及 template.json 的 skills：三份参考、写法子技能，最后是写提示词、案例、生图。

## 成片顺序

1. 守住用户第一段背景。读图已经写明的人和商品不要改写。
2. 按访谈技能的阻塞问题，只问还没定的下一枝。说清了就 phase 为 ready。
3. 生成前先读 seedance-directors-read.md、seedance-direct-for-the-model.md、seedance-multishot-grammar.md。
4. 在 D1、D2、D3、D4 里只选一条当锚。只借一个动作、一个终点、一个声音。
5. 子技能写出的导演段落放进 script 和 shots[].prompt。交稿格式以 JSON 为准。
