这些规则只填进 JSON 字段。script 放整段可复制的短剧提示词。storyboard 用编号分镜。image_prompts 和各张图的 prompt 用生图规则。整段回复不要在 JSON 外面再写正文。

写之前先读 写提示词.md 和 案例.md。在 D1、D2、D3、D4 里只选一条当锚，在 script 里点名它的编号。只借商品在哪一拍、以什么动作进入这场戏。不借人名、台词、商品、地点和镜数。不要把几条案例混成一条，也不要把案例原文贴进 script。

script 必须有这七段：

1. 开场：时长、画幅 9:16、帧率 24、镜头数，以及案例编号。
2. 人物锁定：谁和谁，关系，脸、发型、衣服。不写年龄数字。没有第二个人就写没有。
3. 处境：地点、卡点、光线，并写一行轴线：人物面向哪、商品从哪一侧进入、机位在哪一侧、谁在左谁在右。
4. 商品锁定：哪一件、颜色、必须被认出来的轮廓和材质。不靠商标文字。不写车辆，不写司机。
5. 植入和配比：商品在哪一拍进入，人物用它做什么。一句配比写多少是人和关系，多少是商品被用到的那一下。
6. 编号分镜：一镜一个机位。钩子可以没有商品。植入拍只有一个机位，写人物怎么把商品用完。
7. 风格，加上这场戏会怎么坏的负面清单：口播、价格、商标特写、换脸、第二件同款、第一镜白底商品、跳轴、换房间。

出片规格：画幅固定 9:16，帧率 24。每镜 duration 是 4 到 15 的整数秒，一镜一个机位。对白要能在这一镜里说完。

资产：每个出镜的人一张定妆，subject_kind 用 character，view 为 single。商品写三张，subject 相同，subject_kind 用 prop，view 分别是 hero、three_quarter、macro。微距的 depends_on 填英雄图 id。英雄图、四分之三、定妆和场景的 depends_on 留空。场景是单张，subject_kind 用 location，view 为 single。手持变体才用 single 且 depends_on 填英雄图 id。不要写 front、side、back。上传图只是参考：商品图 id 写入商品三张的 references，人物图 id 只写入对应定妆，不要写进 depends_on，也不要写进镜头 images。姿势和机位不是资产。人物锚点必须能画出来：脸、发型、衣服。商品锚点必须能画出来：轮廓、颜色、材质。场景要写从哪看、前后景和一到三个固定锚点。

生图：所有图片只放进 Image-Node，分镜不新造图片。prompt 用中文，能直接拿去文生图。人物顺序是脸和衣服、景别、光线、背景边界、禁止项。商品顺序是商品锚点、角度、光线和材质、背景边界、禁止项。英雄图是静物，没有手。禁止字幕、水印、商标文字和乱码文字。不要占位符。

分镜：每镜只有一个机位、一个主要运动。镜头数量按钩子、冲突、植入、收束来写，不要为了凑数加空镜，也不要抄案例镜数。第一拍人物已经在处境里，不要从商品轮播开始。duration 是 4 到 15 的整数秒。镜头 prompt 用中文，写这一镜要走完的动作，不要只写一张定格，也不要在同一镜里写第二个机位。没有对白时 dialogue 为空字符串，并写明本镜无对白。有人声时，script 里写成 ==人名：原句==，原句不超过 40 个字，不要写年龄；dialogue 填「人名：原句」。不要另写广告旁白。narration 只放用户图上的原句，没有则为空字符串。下一镜接上这些人的脸和衣服、这件商品、这场光线，以及上一镜的左右关系。images 只列这一镜看得见、且已经写进 Image-Node 的生成资产 id。商品没出场就不要列入。不列上传图。

字段：用 ## 分节。人物、处境、商品和植入拍，用 ==人物锁定== 这种不带冒号的包法。带冒号的 == == 只留给对白。script 按开场、人物锁定、处境和轴线、商品锁定、植入和配比、编号分镜、风格和负面清单来写。view 只能是 hero、three_quarter、macro、single。不要把出镜围栏写进 script 或 shots[].prompt。

出片时以这段为准：画幅固定 9:16，帧率 24。script 是整段可复制提示词，shots[].prompt 是其中一镜，一镜一个机位。每镜 duration 是 4 到 15 的整数秒。只选 案例.md 里的一个案例当锚，只借它的植入节拍，不要把几条案例混成一条。
