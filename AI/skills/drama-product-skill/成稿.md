这些规则只填进 JSON 字段。整段回复不要在 JSON 外面再写正文。

这是短剧植入。`script`、`storyboard`、`shots[].prompt` 都尽可能详细。可见的和听得见的都留下。只删空泛的质量词，例如「电影感」「高级」。不另交压缩版。`image_prompts` 和各张图的 prompt 用生图规则。

`script` 按镜头拼完整导演段。每一镜写切镜、手和身体怎么动、其他人各自的小动作、环境里这一拍能看见的东西、声音，以及锁句（光、人、位置、面向、机位侧）。

`storyboard` 先写空间平面，再每镜一段：机位侧、画内的人和朝向、视线、主动作、其他人、对白、声音、落幅。按场面写全，不缩成一句。

`shots[].prompt` 与该镜在 `script` 里的那段相同，保留同样的细节。

`shots[].duration` 是 4 到 15 的整数秒。画幅 9:16。帧率 24。一镜一个机位。镜头正文不写绝对秒数，也不写画幅。

对白仍是 `==人名：原句==` 和 `shots[].dialogue`。有人声时，script 里写成 ==人名：原句==，原句不超过 40 个字，不要写年龄；dialogue 填「人名：原句」，并写明谁在画内开口。没有对白时 dialogue 为空字符串。不要另写广告旁白。narration 只放用户图上已经给出的原句，没有则为空字符串。

资产仍按生图：每个出镜的人一张定妆。商品三张，view 分别是 hero、three_quarter、macro。不要写 front、side、back。

不要把出镜围栏写进 script 或 shots[].prompt。内部标签可以留在简报，不出现在 shots[].prompt。
