# 短剧植入案例

四条原创节拍，只给 drama-product-skill 使用。写法服从 `seedance-examples-zh.md`：一个动作、一个终点、一个声音。

写之前只选一条当锚，在 script 里点名编号，例如 D1。只借商品在哪一拍、以什么动作进入这场戏。不借人名、台词、商品、地点、镜数和画幅。案例不是成稿，不要把原文贴进 script，也不要把几条合成一条。

## D1 · 顺手解开

钩子这一拍只有人和卡点。商品在第三拍才变成动作。

1. 一个动作：人物已经在做事，手停在半空。终点：手停住。声音：室内环境声。商品不在画面里。
2. 一个动作：一句催促或一段等待把这拍卡住。终点：人还停在原地。声音：那一句，或安静的等待。仍不给商品特写。
3. 一个动作：人物拿起商品，做一个能看懂的使用。终点：这个动作做完。声音：商品碰到手或碰到另一件东西的那一声。光线还是这场戏的光线。
4. 一个动作：人先被看见，商品留在手里。终点：人停住。声音：环境声。没有口播。

借这一条时，植入是「顺手把卡住的事做完」。

## D2 · 递给对方

1. 一个动作：两个人已经在说话。终点：话停在半句。声音：那半句。商品在其中一人身侧，还没被递出。
2. 一个动作：一个人把商品递向对方。终点：对方还没接。声音：衣料或呼吸。
3. 一个动作：交接本身。终点：商品换到另一只手。声音：交接那一声。不看参数。
4. 一个动作：接过的人用它做一件小事。终点：表情变了。声音：使用的那一声。没有口播。

借这一条时，植入是「从一个人交到另一个人」。

## D3 · 本来就在身上

1. 一个动作：人物在包里或口袋里翻找。终点：只露出一点轮廓。声音：翻找声。
2. 一个动作：轮廓被握住。终点：握稳。声音：握住的那一声。机位仍在这个人身边。
3. 一个动作：使用写完。终点：用完。声音：使用的那一声。不旋转，不拉开成展示台。
4. 一个动作：用完放回原处。终点：商品回到刚才的位置。声音：放下的那一声。没有口播。

借这一条时，植入是「它本来就在，现在用一下」。

## D4 · 一句改口

1. 一个动作：旁人先有态度。终点：态度停在那里。声音：那一句。商品在桌上，没被拿起来。
2. 一个动作：主角拿起来用。终点：用完这一下。声音：使用的那一声，或一句和眼前这件事有关的话。
3. 一个动作：旁人改口。终点：只一句说完。声音：这一句。不接着念卖点。
4. 一个动作：停在改口之后的脸。终点：脸停住。声音：环境声。商品留在刚用过的位置。没有口播。

借这一条时，植入是「用一次，换来一句改口」。
