# 短剧植入案例

四条原创节拍，只给 drama-product-skill 使用。写之前只选一条当锚，在 script 里点名编号，例如 D1。

只借商品在哪一拍、以什么动作进入这场戏。不借人名、台词、商品、地点、镜数和画幅。案例不是成稿，不要把原文贴进 script，也不要把几条合成一条。

## D1 · 顺手解开

商品在第三拍才变成动作。前两拍只有人和卡点。

1. 中景，固定机位。人物已经在做事，手停在半空。商品不在画面里。
2. 同一侧稍近。一句催促或一段等待把这拍卡住。仍不给商品特写。
3. 手到半身，一个机位。人物拿起商品，做一个能看懂的动作。光线还是这场戏的光线，不切白底，不环绕。
4. 回到能看见脸的距离。动作做完，人先被看见，商品留在手里。没有口播。

借这一条时，植入是「顺手把卡住的事做完」。

## D2 · 递给对方

植入是一次递交。商品负责这个手势，不负责介绍自己。

1. 两个人已经在说话，距离近，关系是紧的。商品在其中一人身侧，还没被递出。
2. 同一轴线。一个人把商品递向对方，对方还没接。
3. 交接本身是这一镜的全部运动。看清手和这一件商品，不看参数。
4. 接过的人用它做一件小事，表情变了。不解释这是什么。

借这一条时，植入是「从一个人交到另一个人」。

## D3 · 本来就在身上

商品开场就属于这个人，植入拍只是把它用出来。

1. 人物在包里或口袋里翻找。商品还没被拿稳，只露出一点轮廓。
2. 轮廓被握住。机位仍在这个人身边，不换房间。
3. 使用的动作写完。不旋转，不拉开成展示台。
4. 用完放回原处，人停住或离开。商品回到刚才的位置。

借这一条时，植入是「它本来就在，现在用一下」。

## D4 · 一句改口

对白负责转弯。商品只被用一次。

1. 旁人先有态度。商品在桌上，没被拿起来。
2. 主角拿起来用。可以不说话，或只说一句和眼前这件事有关的话。
3. 旁人改口，只一句。不接着念卖点。
4. 停在改口之后的脸。商品留在刚用过的位置。

借这一条时，植入是「用一次，换来一句改口」。
