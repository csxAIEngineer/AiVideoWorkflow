# 万相 3.0 格式支线（格式转换层 · ★权威）

> **定位**：万相 3.0 不是再套一层 H3 壳，而是 P4 投喂封装的**输出壳**。选定本片走万相后，只做一件事：把本包已经锁定的分镜、资产、对白和声音，转成万相 3.0 的原生提示词。
>
> **支线边界**
> - **不动的部分**：P0~P3 全流程、资产链、台词原文、段缝 D 锁、看板——一律不改。
> - **动的部分**：只有 P4 投喂封装的输出壳。不要再写成 MiniMax H3 的英文字段，也不要写 `<d>` 或 `[Chinese]`。
> - **一句话**：上游（剧作/分镜/资产/时长/对白原文）由本包供给，下游只换壳。

> **核对来源（对照原文，非推测）**
> 1. 阿里云百炼《万相3.0视频生成Prompt指南》的完整公式、台词写法与负向清单。
> 2. 官方 `wan3-pe` Skill v0.2.0：只整理已有内容，不扩写剧情，台词逐字保留，画幅/总时长/分辨率不写进正文。
> 3. 千问技能市场 `@qianwen-ai/qianwen-video-generation` 的 `references/prompt-guide.md`（主体+场景+运动、台词与声音分写、多镜头序号+时间戳）。

## 一、输出公式

官方完整公式如下。想控制什么就写上；**栏名必须保留，无内容写「无」，不要删栏**（机检要求七栏齐全，缺栏即 FAIL），也不要为了凑段而编造。

```
提示词 = [总体描述]
       + [参考素材引用：图 N / 视频 N / 音频 N]
       + [分镜 N（起-止秒）：主体 + 场景 + 运动 + 美学控制]
       + [台词：xx 说："xxxx"]
       + [音效 / BGM]
       + [风格 / 情绪]
       + [负向清单]
```

每个封装单元交一份这样的提示词，不要改用 `integrated_multimodal_description` / `subject_definitions` / `overall_soundscape` / `non_diegetic_music` 那四个英文字段。

## 二、本包稿源 → 万相字段

| 本包稿源 | 万相目标 | 转换动作（硬要求） |
|---|---|---|
| 单元标题与算好的 `duration` | 总体描述里的主题/节奏；分镜起止秒 | 总时长和画幅走接口参数，不写进正文。分镜时间戳必须用封装已经算好的起止秒，不要自行改时长，也不要钳短。万相单段时长 2–30 秒（另支持 -1 智能时长）；官方文档里 2–5 秒只是单镜示例，不是本片硬上限 |
| 【画幅风格】或画面风格锁定句 | 风格 / 情绪 | 把已锁定的画风、色调、情绪写成可见要素，放在提示词开头或结尾。不要改写成空词，也不要另造画风 |
| 资产锁、分镜「资产：」里的图号 | 参考素材引用：图 N | 只引用已经锁定的图号，写清采用范围（外貌/服装/场景/道具）。无图不编造。`@CHR` / `@SCN` / `@PRP` 锚点全删，改成图号和名称 |
| 时间轴分镜、镜号骨架 | 分镜 N（起-止秒）：主体 + 场景 + 运动 + 美学控制 | 通篇只用一种时间戳写法，推荐 `分镜1（00:00-00:03）：`。写主体、场景、动作、景别和运镜。切镜用「硬切转场」或「从上一分段的最后一帧无缝衔接」。不要写模型控不住的高频动作 |
| 对白 / 旁白原文 | 台词：xx 说："xxxx" | 格式是「角色 + 说话动词 + 冒号 + 引号原文」，例如 `阿宁说："今晚先别回去。"`。多人逐句标明说话人。旁白写成 `画外音："……"`。无对白必须显式写 `无台词`，不要留空让模型自己补词 |
| 镜行「声音：」、环境音、BGM | 音效 / BGM | 环境音、动作音、BGM 与台词分开写。不要把声音行写进台词 |
| 情绪、情节、表演提示 | 风格 / 情绪，或分镜动作 | 不要把「情绪：」「情节：」整段写进台词行。情绪进风格段，情节进分镜动作 |
| 用户或锁已经提出的排除项 | 负向清单 | 只写不希望出现的内容。没有就写「无」，不必凑数，但不要删掉这一栏。只使用官方指南已有的项，以及用户或锁已经提出的排除，不要自造新负向词。本片出镜锁使用官方三项：`不要字幕`、`不要水印`、`不要复杂文字` |

## 三、硬约束

1. **台词原文锁定**：用户和分镜里已经写出的对白逐字保留，不改词、不删前缀、不把一句拆成另一句。用户只写了说话意图、没给原文时，保留那段意图，不自己编对白。
2. **禁止 H3 对白壳**：不要写 `<d>`、不要写 `[Chinese]`、不要写 `says in an off-screen voiceover` 这类 H3 英文公式。万相对白就是 `xx说："内容"`。
3. **禁止把非对白塞进台词**：情绪、情节、动作提示、声音设计都不是台词。
4. **素材不编造**：只引用上游已经给出的图、视频、音频编号。没有的素材不要发明编号，也不要劝模型去补一张不存在的图。
5. **参数分离**：画幅、总时长、分辨率、帧率不写进提示词正文。
6. **不扩写剧情**：不加入上游没提过的人物、事件或结局。
7. **首帧拼接**：后续单元若继续上一段，在分镜开头写明从上一单元尾帧无缝衔接，不要把下一场硬填进来凑满 30 秒。

## 四、P4 封装

封装专员只填这个输出壳。每个单元先写总体描述和素材引用，再按骨架写出带起止秒的分镜，然后单独写台词、音效/BGM、风格/情绪和负向清单。已经填好的单元保留，空着的槽只补正文。修补时只改机检点名的问题。
