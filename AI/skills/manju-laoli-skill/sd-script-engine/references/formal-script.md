# 正式剧本

本节点只写本集干净正式剧本。简报里的锁、时长、画幅和已提供事实只读，不改锁。来源登记、台词怎么说得像人、对白诊断和圆桌审核由其他节点负责，这里不写那些交付物，也不写资产库、分镜或投喂。

## 步骤

1. 从简报抄齐本集要写的事实：时长、画幅、已锁定来源、必须保留的情节和关键台词。
   完成标准：简报里出现的锁和必须保留项都进了写作依据；缺了必要锁就点名缺哪一项，不补猜。

2. 把本集写成能连续复述的完整故事单元，按场次排好因果。
   完成标准：每场都有人带着具体目标进场，并因对手、规则、环境或关系的反应而改变做法，场末至少改变目标、关系、信息、资源或危险之一；下一场由这一场的结果、决定或新压力触发。交出来的是能演的故事，不是梗概、节拍清单或名场面拼贴。

3. 用下面的干净剧本格式写出可见动作和可演台词，并按已锁时长写满。
   完成标准：正文只有场头、出场、动作、台词和必要的音效或屏显；没有质量门、来源说明、镜头指令或自评。时长与已锁目标一致，不靠删掉故事或因果来赶时间。

4. 通读正文，只留演得出、且有来源或简报支持的内容。
   完成标准：主线、人物动机、关键关系、世界规则、趣味点和关键台词功能都还在；冲突由目标、策略、反制、换策和代价推进，本集该兑现的先兑现。没有来源支持的关键身份、能力、秘密、证据、规则、关系、胜负、谜底或结局，一律不写进正文。

## 干净剧本格式

```markdown
# 第001集｜工作标题

- EPISODE_ID：EP001
- SCRIPT_VERSION：SCRIPT-V1
- DURATION_TARGET：60 秒
- ASPECT_RATIO：16:9

## EP001-SC01｜内·地点·夜（0s - 15s）

出场：角色甲、角色乙

▲ 可见动作。人物因阻力改变做法。

角色甲：具体台词。

角色乙（O.S.）：画外或内心。

【音效】必要的声音。

## 本集结束
```

场头写内外、地点、日夜；有锁定时长时，场头同时写清起止秒。地点、时间或人物状态发生真实变化时才换场。正文只写看得见的动作、空间关系、人物反应和可表演的停顿，以及简短必要的表演提示。

台词只写成 `角色名：台词文本`，角色名必须是具体人名或称谓，冒号全篇统一。画外或内心写 `角色名（O.S.）：…`；旁白写 `旁白者名（VO）：…`，没有具名时才写 `旁白（VO）：…`。`（O.S.）` 和 `（VO）` 只说明声音怎么出来，不是角色名。

说话人用真名或称谓，例如 `林遥：放下。`。通道标记写在括号里，例如 `林遥（VO）：…`，不要把 VO、OS 直接接在名字后面。

## 写法

把心理和叙述变成可见行动、反应、空间、道具或策略对白。优先顺序：人物行动结果，然后是对手反应，然后是道具或环境证据，然后是对白，最后才是旁白。

每句台词都要推动人物塑造、冲突、信息、情绪或必要节奏。先想人物此刻想让对方做什么，再写他说什么。口语、称呼和怎么避免机械腔，以 `dialogue-naturalization.md` 为准。

开场前 10 秒给出有来源支持的爆点、最小处境和此刻必须行动的理由。对手先立住，再写翻盘；主角主动做事，代价要在正文里发生。已经承诺的答案按时兑现；人物选择来自已有动机，而不是套用流行套路。

简报给定了时长，就按这个时长写完整故事。可以压缩重复过程，但因果、动机、代价和结果要保留。

## 边界

本节点的产物是干净剧本正文。审稿账本、质量门列表、圆桌意见和精修方案留到对应节点。景别、机位、运镜、灯光和剪辑指令留给分镜阶段。
