# 电影级汽车广告

同一台车从头到尾是同一台车。速度写在机位和掠过的东西上。语气是汽车广告：安静、贵气，看金属、漆面、轮胎和路面，不要写成说明书，也不要写成追逐枪战。

## 交稿

只返回一个 JSON 对象。`script`、`storyboard`、`image_prompts`，以及 `assets` 和 `shots` 里的提示词全部用中文。不要在 JSON 外面写锚点链接、检查清单或引导语。不要向用户追问画幅、时长或语言。简报已经锁定这台车、这条路和机位。

生图按 iCreat 的静帧来写。出镜按 MiniMax 的参考图视频来写运动。下面三条出镜围栏由出片程序拼接，不要写进 script，也不要写进 `shots[].prompt`。

## 规格

- 画幅 9:16。
- 帧率 24。
- 每镜 `duration` 是 4 到 15 的整数秒。
- 一镜一个机位、一个主要运动。
- 镜头数按出发、速度、收束来写，不抄案例里的总镜数。第一拍的写法见下面「三拍」。

## 三拍

第一拍是出发，整拍只有一个运动：从远景起幅，镜头收缩，移向已经在行驶的这台 SUV。车在这一拍开始时就在走，不是从停车起步。远景里先是这条路和光线，车在其中。落幅停在能认清车身的距离。不要在这一镜里再切到第二个机位。

第二拍从这一落幅接着走。车头朝向、沿路方向和机位侧与第一拍落幅相同，机位不再退回远景。

第三拍收在漆面、车身姿态和轮胎接地。车已经停稳或即将停稳时，车头仍朝第一拍落幅的方向，不要把车尾掉转成车头。

## 全片轨迹

写编号分镜之前，先在 `script` 里写一行全片轨迹：车头朝哪、沿路往哪开、路的某一侧（海、山或街）始终在车的哪一侧、机位默认在车身哪一侧。

每一镜落幅的车头朝向、沿路行驶方向和机位侧，必须由这一镜的运动走出来，并原样成为下一镜的起点。可以改景别和远近，不得调头，不得换到车身另一侧。

这一镜的 `images` 必须和机位侧一致：跟在车后用背面，贴在固定一侧用侧面。不要为了换角度改用正面，把镜头绕到车头前。

## 工作流

1. 读 `案例.md`。只选一条最接近这条片子镜头运动的案例，在 `script` 里点名它的编号，例如 E4。不要贴链接。
2. 只借这一条怎么把速度写进机位和掠过的东西。不借它的画幅、一秒一镜、车型、人物、武器和变形。E4《Motorcycle Racing Through a Mountain Road》把机位压到路面，草和护栏被甩过去。它的 16:9，以及 CUT 01 到 CUT 16，不要交出去。
3. 先写全片轨迹，再按下面七段写 `script`。
4. 按资产规则写 `assets`，按分镜规则写 `shots`。`shots[].prompt` 是 `script` 编号分镜里的一镜。
5. 核对负面清单，然后只交 JSON。

## 七段

1. 开场：总时长、画幅 9:16、帧率 24、镜头数。
2. 车辆锁定：车型、颜色、轮廓，以及必须动对的部件：悬挂压缩、轮子转动、引擎震动。按部件写，不靠车标。
3. 司机锁定：没有司机就写「没有」，并且不要写司机图。有司机就锁体型和装备，不要再写人物定妆三视图。
4. 路面和天气：铺装、路两边、光线，加上全片轨迹那一行。同一条路是一条不折返的路径：不换地点，也不在中途把车头调转。
5. 配比：多少是镜头运动，多少是风景。下面的分镜照这句执行。
6. 编号分镜：一镜一个机位。每镜写机位、运镜、起点、车子怎么动、掠过什么、终点，以及 4 到 15 的整数秒。第二镜起，起点必须复述上一镜的落幅朝向。不要把一镜拆成一秒一条。
7. 风格和负面清单：实拍电影质感。排除重复部件、错误的轮子几何、悬浮、车标文字特写、字幕、水印和乱码文字。特写打在轮胎接地、悬挂压缩和排气上。

## 资产

主角车辆三张，`subject` 相同，`subject_kind` 用 `prop`，`view` 分别是 `front`、`side`、`back`。侧面和背面的 `depends_on` 填正面 id。正面和路面的 `depends_on` 为空字符串。

路面一张，`subject_kind` 用 `location`，`view` 为 `single`。换色、天气、伤损是变体：`view` 为 `single`，`depends_on` 填该车正面 id，不要再拆三视图。

上传图只是参考。要参考时，`references` 填上传图 id，例如 `["U1"]`。不要把上传图 id 写进 `depends_on` 或镜头 `images`。侧面和背面不要再写上传图。没有司机就不要写司机图。

## 这些句子作废

案例原文里如果还有这些句子，不要执行：

- 一秒一条，或先写满 16 个一秒镜头。
- 向用户追问画幅、时长、语言或参考图。
- 用英文写提示词，或在 JSON 外面交一条可复制的视频提示词。
- 在回复里附案例链接和三行检查清单。
- 把出镜围栏抄进 `script` 或 `shots[].prompt`。
- 在同一条路上把车头调转，或把机位从车身一侧换到另一侧、换到车头前。

## 出镜时接上

本技能只属于高奢感 SUV。写 JSON 时不要抄下面三句。参考图出镜时，出片程序会把它们接上。首尾帧模式不接这三句。

```render-video-lock
锁同一台车：轮子在转，车不悬浮，不新造部件，不特写车标文字。全程无字幕、无对白文字叠加。
```

```render-video-next
这一镜是上一镜的下一刀。车头朝向、沿路方向和机位侧与上一镜落幅相同，不得调头，不得换侧。同一台车接着走，轮子继续转。
```

```render-video-tail
最后一张参考图是上一镜的实际尾帧，只承接这台车、光线和路面，不要照抄它的景别和构图。
```
