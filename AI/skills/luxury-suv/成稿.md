这些规则只填进 JSON 字段。script 放整段可复制的汽车视频提示词。storyboard 用编号分镜。image_prompts 和各张图的 prompt 用生图规则。整段回复不要在 JSON 外面再写正文。

写之前先读 写提示词.md 和 案例.md。选一个最接近这条片子镜头运动的案例当锚，在 script 里点名它的编号。只借这一条怎么把速度写进机位，不借它的画幅、一秒一镜、车型和剧情。不要把几条案例混成一条。

script 必须有这七段：

1. 开场：时长、画幅 9:16、帧率 24、镜头数。
2. 车辆锁定：车型、颜色、必须动对的部件（悬挂、轮转、引擎）。按部件写，不靠车标。
3. 司机锁定：没有司机就写没有；有司机就锁体型和装备。
4. 路面和天气，并写一行全片轨迹：车头朝哪、沿路往哪开、固定一侧始终在车的哪一侧、机位默认在车身哪一侧。不得调头，不得换侧。
5. 一句配比：多少是镜头运动，多少是风景。
6. 编号分镜：一镜一个机位。速度写在机位和掠过的东西上。
7. 风格，加上车辆会怎么坏的负面清单：重复部件、轮子几何、悬浮、车标特写。

出片规格：画幅固定 9:16，帧率 24。每镜 duration 是 4 到 15 的整数秒，一镜一个机位。速度写在机位和掠过的东西上。

资产：主角车辆写正面、侧面、背面，subject 相同，subject_kind 用 prop。路面是单张，subject_kind 用 location，view 为 single。没有司机就不要写司机图。有司机时把体型和装备写进说明，不要为人物再写一套定妆三视图。换色、天气、伤损是变体，view 为 single，depends_on 填该车正面 id。上传图只是参考：引用它的资产把上传图 id 写进 references，不要写进 depends_on，也不要把它当成已经生成的资产。侧面和背面的 depends_on 仍填生成好的正面 id，上传图只写在直接参考它的那张资产上。姿势和机位不是资产。车辆锚点必须能画出来：车型、颜色、轮廓、必须动对的部件。路面要写铺装、路两边和光线。同一条路不因昼夜或天气再建成另一个地点。

生图：所有图片只放进 Image-Node，分镜不新造图片。主角车辆写正面、侧面、背面，同一个 subject。prompt 用中文，能直接拿去文生图。顺序是车辆锚点、当前变体、角度、光线和材质、背景边界、禁止项。写成实拍：金属和漆面可以有磨损，轮胎接地，不要悬浮，不要重复部件，不要特写车标文字。车辆正面和路面的 depends_on 留空。车辆正面要对齐上传图时，references 填上传图 id。侧面和背面的 depends_on 填正面 id。路面写清从哪看向哪、前后景，以及一到三个固定锚点。禁止字幕、水印、logo 和乱码文字。不要占位符。

分镜：每镜只有一个机位、一个主要运动。镜头数量按车子的节拍来，拍完出发、速度和收束，不要停在固定个数，也不要为了凑数加空镜。第一拍是出发：从远景起幅，镜头收缩，移向已经在行驶的这台 SUV，落幅停在能认清车身的距离。车在这一拍开始时就在走。第二拍从这一落幅接着走，不再退回远景。写清这一镜的机位、运镜、起点、车子怎么动、掠过什么、终点。第二镜起，起点必须复述上一镜的车头朝向、沿路方向和机位侧。可以改景别，不得调头，不得换侧。跟在车后用背面，贴在固定一侧用侧面，不要改用正面把镜头绕到车头前。duration 是 4 到 15 的整数秒。镜头 prompt 用中文，写这一镜要走完的运动，不要只写一张定格，也不要在同一镜里写第二个机位。没有对白时 dialogue 为空字符串，并写明本镜无对白。有人声时 dialogue 填这一句原话。下一镜接上这台车的颜色、路面、光线，以及上一镜的落幅朝向。images 只列这一镜画面里要保持的、已经写进 Image-Node 的生成资产 id，不列上传图。

字段：用 ## 分节。车辆锁定、路面、配比和镜头机位，用 ==重点== 包起来。script 是整段可复制的汽车视频提示词，按开场、车辆锁定、司机锁定、路面和天气、配比、编号分镜、风格和负面清单来写。view 只能是 front、side、back、single。主角车辆写 front、side、back 三张，subject 相同，subject_kind 用 prop；侧面和背面的 depends_on 填正面 id。路面 view 为 single，subject_kind 用 location。变体 view 为 single，depends_on 填该车正面的 id，不要再拆三视图。不要为人物再写一套定妆三视图。车辆正面和路面的 depends_on 为空字符串。上传图只是参考，不是资产。要参考上传图时，references 填上传图 id，例如 ["U1"]，不要把上传图 id 写进 depends_on 或镜头 images。侧面和背面依赖生成好的正面。shots[].prompt 是 script 编号分镜里的一镜，写这一个机位和掠过的东西。每镜 duration 写 4 到 15 的整数，不要把一镜拆成一秒一条。提示词里禁止字幕、水印、乱码文字和车标特写。不要把出镜围栏写进 script 或 shots[].prompt。

出片时以这段为准：画幅固定 9:16，帧率 24。script 是整段可复制提示词，shots[].prompt 是其中一镜，一镜一个机位。每镜 duration 是 4 到 15 的整数秒。只选 案例.md 里的一个案例当锚，只借它的镜头运动，不要把几条案例混成一条。
