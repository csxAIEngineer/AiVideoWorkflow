# Image-Node

一条视频由多个节点组成。每个节点只处理一个分镜，或一个特定的功能。一个节点里可以有多张资产图。

Image-Node 是必须的功能节点：用来生成所有视频内用到的图片。每个人一张定妆；广告商品写英雄图、四分之三、微距；场景是单张；每一镜另有一张关键帧。再次强调，所有视频用到的图片都要先经过Image-Node处理/生成。

人物定妆、商品三视图和场景单张只锁身份。关键帧另写，按九段写能看出动作的姿势，不由定妆或商品图代替。出图围栏不写脸，也不写商品。

## 节点

- 功能节点做一件功能。Image-Node 是其中必须有的一个，而且是唯一产图的节点。提示词、分镜、拼接、字幕、成片也是功能节点，它们不产图。
- 分镜节点一个节点只处理一个分镜。它只引用 Image-Node 里已经有的图，不在这个节点里新造图片。
- 一张图只写在 Image-Node 里。分镜节点里看见的图，是从 Image-Node 拿来用的。

## 必须生成的图

每个要出镜的人一张，`subject_kind` 用 `character`，`view` 为 `single`。标题写明定妆。这张锁定脸、发型、衣服和体态。定妆里不拿商品，除非商品本来就戴在身上。不要把同一个人再拆成正面、侧面、背面。定妆不写这一镜的动作。

广告商品三张，`subject` 相同，`subject_kind` 用 `prop`：

- `hero` 英雄图。静物，这场戏的光线，没有手，看清完整轮廓。
- `three_quarter` 四分之三。看清体积和一条侧棱。
- `macro` 微距。只放大植入拍要看清的那一处细节。

场景只写一张，`subject_kind` 用 `location`，`view` 为 `single`。无人物，商品不占特写。写清从哪看向哪，以及一到三个固定锚点。场景不写这一镜的动作。

每一镜另有一张关键帧。`subject_kind` 为 `other`，`view` 为 `single`。标题写明这一镜的关键帧，不要写成定妆，也不要写成商品的第四个角度。`depends_on` 留空。`prompt` 用中文，按九段写：景别和焦段、身份、能看出动作的姿势、衣服和道具、地点、光源和光比、构图、质感、约束。身份、地点、光源从导演书原句抄，不要改写。镜头 `images` 把这张放在第一位，出片用它当首帧。

微距的 `depends_on` 填英雄图的 id。英雄图、四分之三、定妆和场景的 `depends_on` 留空。三张商品图是三张单独的图，不要拼进同一张。

手持或使用中的样子不是第四个角度，也不是关键帧的替代。商品被用到的那一拍写进这一镜的关键帧。

其他道具保持单张。不要给它们写 `hero`、`three_quarter`、`macro`，避免被认成广告商品。

上传图只是参考，不是资产，也不放进镜头。商品上传图的 id 写进英雄图、四分之三、微距的 `references`。人物上传图的 id 只写进这个人的定妆。两边不要交叉。不要把上传图 id 写进 `depends_on`。生成出来的资产图才绑定提示词和分镜。

## 字段

每张资产图都写 `id`、`title`、`prompt`、`depends_on`、`references`、`subject`、`subject_kind`、`view`。

- `subject_kind`：`character`、`prop`、`location`、`other`
- `view`：`hero`、`three_quarter`、`macro`、`single`
- `references`：上传图 id 的数组。没有参考图时为 `[]`。上传图只是参考。

`prompt` 用中文，能直接拿去文生图。定妆先写脸、发型、衣服，再写景别。商品先写轮廓、颜色、材质，再写这一面的角度。关键帧按上面的九段写。镜头的 `images` 只能填 Image-Node 里要生成的资产 id，不能填上传图 id，并且第一项是这一镜的关键帧。商品没在这一镜出场，就不要把商品 id 放进这一镜。

## 禁止

不要在分镜、拼接或成片节点里写一张 Image-Node 没有的新图。
不要只给商品一张英雄图。缺四分之三或微距时，按同一件商品补上。定妆和场景保持单张。
不要少掉这一镜的关键帧，也不要用定妆或商品图充当这一镜的首帧。
不要写 `front`、`side`、`back`，不要写车辆。
不要把上传图写成资产，也不要放进镜头的 `images` 或资产的 `depends_on`。
不要把人物参考图写进商品，也不要把商品参考图写进定妆。

## 出图时接上

这段只属于短剧植入 · 导演的 Image-Node。出图时把下面这一句接在每张图片提示词末尾。

```render-image
实拍照片质感，可用光，不要字幕，不要水印，不要商标文字，不要乱码，不要CG渲染。
```
