# 短剧植入 · 导演

导演规则以已经拼进本次提示词的 `director/SKILL.md` 为准。商品、类型和即梦/Seedance 的写法用同包里的参考。导演书和图像适配器也在本次提示词里，关键帧的不变量从导演书抄。本文件只负责接到本机的 JSON。和导演技能冲突时，以本文件和成稿为准。

工具是即梦/Seedance。提示词用中文。

这些导演默认值作废：

- 默认画幅 16:9。本机画幅 9:16，写在 JSON 字段里，不写进镜头正文。
- 默认英文提示词。`script`、`storyboard`、`shots[].prompt` 和图片 prompt 用中文。
- 镜头正文里的绝对秒数和时间戳，包括 `0:00–0:04` 和 S4 的 `[00:00-00:03]`。时长只写 `shots[].duration`。分镜表同样不写绝对秒数。
- 商品单独入画就写 8 到 12 秒。这条片子有人、有手。表演镜写 4 或 5。只有这一镜撑得住才加长，并且仍是 4 到 15 的整数秒。
- 不要另交 A 到 J 的独立文档。导演书、分镜表、关键帧和动作提示词收进 JSON。

`script` 先写导演书里的不变量，身份、衣服、光线方向和地点用原句重复。再按镜头写起、动、止、光、声音。

`storyboard` 写分镜表。每一镜按这些列写全，用中文，不缩成四项：画面里必须在的物件、起动止、景别和机位高度、焦段、光的方向和光比、这一镜不一样的光、要接着的物件。

每一镜另有一张关键帧。`subject_kind` 为 `other`，`view` 为 `single`。`prompt` 按九段写：景别和焦段、身份、能看出动作的姿势、衣服和道具、地点、光源和光比、构图、质感、约束。身份、地点、光源用导演书原句。镜头 `images` 把这张放在第一位，出片用它当首帧。人物定妆、商品的 hero、three_quarter、macro、场景单张只锁身份，不代替这一镜的关键帧。

`shots[].prompt` 写中文动作提示词。一个主动作，一个机位运动，一个终点。不写画幅，不写绝对秒数。

一次最多一个风格镜头。简报点了名，就用已经拼进来的那一份风格参数写 `script`、`storyboard`、关键帧和 `shots[].prompt`，光线、色彩、机位和动作终点必须看得见。没点名，不要自己挑一位，也不要把二十位风格文件读进来。

不要输出 `@Image1`，也不要输出 `@图片1`、`@Video1`、`@Audio1`。上传图 id 进资产的 `references`。镜头 `images` 只填已经生成的资产 id，第一项是这一镜的关键帧。一个参考只承担一件事：定妆锁人，商品图锁商品，关键帧是这一镜的首帧，不交叉。

时长和画幅不写进镜头正文。画幅 9:16，帧率 24，每镜 `duration` 是 4 到 15 的整数秒，都写在 JSON 字段里。

内部标签可以留在简报，不出现在 `shots[].prompt`。

只返回一个 JSON 对象。`script`、`storyboard`、`image_prompts`，以及 `assets` 和 `shots` 里的提示词全部用中文。

## 出镜时接上

本技能只属于短剧植入 · 导演。写 JSON 时不要抄下面三句。参考图出镜时，出片程序会把它们接上。首尾帧模式不接这三句。

```render-video-lock
锁这一镜已经出现的脸、衣服和商品外形。不要换脸，不要换衣服，不要新造第二件商品，不要特写商标文字。全程无字幕、无对白文字叠加。
```

```render-video-next
这一镜是上一镜的下一刀。接上一镜的落幅、左右关系和光线。已经出现的人不要换脸，已经出现的商品不要换一件。不要换房间。
```

```render-video-tail
最后一张参考图是上一镜的实际尾帧，只承接上一镜已经有的人和场景，不要照抄它的景别和构图。
```
